# 通用天文学图表的适用范围

工具按科学量与图形表达工作，研究对象不限定为双星或三星。可读取各种天体的观测、模拟、统计或理论结果；具体图型优先使用已注册入口，也可通过 Matplotlib/Plotly 自定义接口表达，再统一保存源数据、图注、版本和导出检查。

“适用于各类天体”表示对象类别不构成输入限制，且有通用扩展路径。它不表示已内置所有专业科学计算、仪器标定、数据格式解码或每本期刊的终稿验收。当前实际可执行入口及必需字段以 `list` 为准；验收记录说明哪些入口已实跑，不能把本范围表当作这些入口之外的完成证明。

| 系外行星及行星系统 | 凌星、食、RV、透射/发射谱、成分与种群 | 光变及残差、相位图、波长—半径比/深度、质量—半径、完备度 | 时间基准、归一化、去趋势、星斑与仪器分组；深度/半径比不可混作同一量 | 既有光变/RV/相位/质量半径/选择函数机制；专门透射谱和多波段入口以运行时列表为准，推断由上游模型完成 |
| 恒星、褐矮星、双星与多星 | 结构、演化、脉动、磁活动、质量交换、动力学 | HR/CMD、演化轨迹、频谱、Roche 等势、食几何、长期演化、后验图 | 温度或颜色的横轴定义、绝对/视星等、距离与消光处理、成分及轨道约定 | 保留全部双星/三星入口；`hr_diagram`、`transfer_history`、`roche_map`、`eclipse_geometry`、`polarimetry` 与统计通用接口 |

| 宇宙学、大尺度结构、CMB 与背景辐射 | 距离、膨胀、分布、相关结构、功率谱与模型比较 | Hubble 图、红移分布、天空图、相关函数、角/三维功率谱、协方差和后验 | 距离种类和宇宙学参数、共动/物理量、`h` 因子、谱估计定义、窗口/掩码与单位 | 通用线/散点/矩阵/后验与天图；Hubble/角功率谱入口读取给定计算结果，不自动选宇宙学或估计去偏谱 |
| 仪器、巡天、方法及种群统计 | 响应、灵敏度、标定、误差、选择偏差、算法性能 | 响应/噪声曲线、覆盖图、完备度、直方/密度图、残差、误差—成本图 | 仪器模式、响应量、曝光、独立采样单位、选择分母、硬件和精度目标 | `selection_function`、`uv_coverage`、统计分布/诊断/收敛/benchmark、天图与多面板；新仪器格式经明确适配后使用 |

这里列举的对象可交叉组合。例如，银河中的食双星可以同时需要轨道、光变、天测、CMD 和巡天天图；瞬变宿主研究可以同时需要定位、图像、光谱和星系统计。图型按问题组合，不按对象标签互斥分组。

## 接入前的共同约定

- **坐标与图像。** 保留坐标系、角度单位、参考历元、WCS、像素起点和数组轴顺序。普通像素图不是已校准天图；在错误 WCS 上绘出漂亮坐标网格不能建立正确天测。Astropy 区分像素坐标 `(x, y)` 与数组索引 `(row, column)`。[WCS 说明](https://docs.astropy.org/en/stable/wcs/index.html)
- **时间与频谱。** 记录时间表示和时间尺度，观测者/静止系、光行时或重心修正、频率/波长以及光学/射电速度定义。转换必须来自明确计算与适用条件，不能仅凭列名或单位缩写推断。[时间说明](https://docs.astropy.org/en/stable/time/index.html)、[量纲及等价变换](https://docs.astropy.org/en/stable/units/index.html)
- **计量与统计。** 图注区分通量、流量密度、面亮度、星等、计数、概率、概率密度及不同区间定义。保留掩码、上限、选择条件、响应、背景和已执行的归一化；不同对象或仪器按对应元数据分组。
- **多图比较。** 共用色标不代表图像已经重投影、PSF/波束匹配或交叉标定。采用不同尺度时标明理由；物理可比性由数据处理证据建立，图形软件不补做未声明的预处理。

## 需专门软件或适配的研究产物

| 数据或算法 | 推荐接法与需要验证的内容 | 本工具的边界 |
| --- | --- | --- |
| FITS 多扩展图像、表与立方 | 明确 HDU、轴、切片/通道、单位、标定和掩码；保留头信息及原文件标识 | 普通二维读取与显示不等于支持所有压缩、失真查找表或多维相关 WCS。FITS 存储格式本身不保证科学校准。[FITS 文档](https://docs.astropy.org/en/stable/io/fits/index.html) |
| 复杂 WCS、重投影、拼接及尺度匹配 | 用经过验证的 WCS/配准与重投影过程输出；记录插值、覆盖区和通量/面亮度约定 | `image_montage` 一类显示拼图不承担配准；`reproject` 也以输入 WCS 正确为前提，重采样方案的测光性质需单独检查。[官方说明](https://docs.astropy.org/projects/reproject/en/latest/index.html) |
| HEALPix、MOC 与定位可信域 | 按需接入 healpy、ligo.skymap 等；保存 NSIDE/分辨率、RING/NESTED、坐标系、无效像素及概率定义 | 普通规则经纬网不能直接冒充 HEALPix；显示像素值不能自动得到有效可信域。[healpy](https://healpy.readthedocs.io/en/latest/tutorial.html)、[ligo.skymap](https://lscsoft.docs.ligo.org/ligo.skymap/) |
| CASA MeasurementSet、干涉成像与射电谱立方 | 用适当版本的 CASA 等完成标定、成像、去卷积、波束和通道处理，接入已导出的数组/表/WCS | UV 覆盖图不执行成像，PV/矩图显示不验证谱线选择和掩码造成的偏差。[CASA 图像分析](https://casadocs.readthedocs.io/en/stable/notebooks/image_analysis.html) |
| MHD、N 体、GR/GRRT、辐射转移、流体与化学网络 | 从实际求解器导出有单位、坐标、边界条件和误差记录的场、网格、粒子、轨迹或辐射量；必要时做专门读入器 | 等高线、流线、影像或轨迹绘制不执行这些物理求解，也不以图像外观验证守恒、收敛或模型近似 |
| 专用事件、响应、源表与巡天目录 | 依据产品数据模型接入，保留事件选择、响应/曝光、质量标志和来源版本；需要时采用领域软件处理 | 通用表格入口不解释所有原生容器或自动纠正选择偏差；未知字段保持原义 |

专用依赖按具体任务安装、固定版本并验证，不为“覆盖所有天体”一次引入所有软件。已有科学软件生成的 Matplotlib/Plotly Figure 也可使用统一导出接口；接入时继续交付源数据、生成代码和真正完成的检查。

## 期刊与最终使用

对象范围扩展不会自动扩大期刊合规范围。使用本工具的期刊配置时，仍区分官方门槛、工具建议、未核实项、文章类型和投稿阶段；原生表格模板、机器可读补充数据及最终文件在实际目标期刊下验证。运行成功、格式检查或合成示例通过都不能代替科学分析验收。

参考资料的核查日期及使用目的见 [astronomy-sources.md](astronomy-sources.md)。
